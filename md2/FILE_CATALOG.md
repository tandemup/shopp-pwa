# Catálogo resumido de archivos

| Ruta | Responsabilidad |
|---|---|
| `App.js` | Inicializa Expo, Convex y el contexto de autenticación. |
| `src/navigation/` | Stacks y pestañas de navegación. |
| `src/screens/auth/` | Registro, inicio de sesión y recuperación de contraseña. |
| `src/screens/lists/` | Listas, artículos y búsqueda predictiva. |
| `src/screens/scanner/` | Escáner, producto, edición e historial. |
| `src/screens/stores/` | Catálogo, favoritos, mapas y detalle de tiendas. |
| `src/screens/chat/` | Chat y noticias. |
| `src/screens/parking/` | Parking, preferencias y diagnóstico GPS. |
| `src/screens/admin/` | Administración de usuarios y revisiones. |
| `src/context/` | Estado compartido de listas, tiendas, ubicación y aprendizaje. |
| `src/storage/` | Persistencia local y claves de almacenamiento. |
| `src/services/` | Búsquedas externas, exportación, historial y seguridad de URL. |
| `src/components/` | Componentes reutilizables, mapas, escáner y controles. |
| `src/utils/` | Precios, categorías, distancias, mapas, validación y formato. |
| `convex/` | Esquema, autenticación, consultas, mutaciones, crons y autorización. |
| `public/` | Manifiesto, service worker y redirecciones de la PWA. |
| `docs/` | Landing page, privacidad y soporte para publicación estática. |

Los archivos de diagnóstico, semillas, snippets y documentación interna pueden existir en el repositorio sin formar parte del flujo normal de usuario.
